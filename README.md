# Blog alias

The canonical blog is https://james-wang-sage.github.io/ and its source repository is
https://github.com/james-wang-sage/james-wang-sage.github.io.

Kaopu AI, Valsar Tan and Lodi-Pine host these static redirect pages.
HTML pages redirect to the canonical site at the same path. JavaScript preserves
query strings and anchors; the custom 404 page handles paths added in the future.
Assets stay available for existing direct downloads.

The Atom feed is a migration snapshot. Subscribe to https://james-wang-sage.github.io/feed.xml
for future updates. Publish new articles only to the canonical repository.
